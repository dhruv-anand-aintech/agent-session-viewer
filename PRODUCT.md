# Product

## Register

product

## Users

Developers and coding-agent operators use Agent Session Viewer to inspect live and archived Claude Code, Cursor, Codex, OpenCode, Hermes, and Antigravity sessions across local projects.

## Product Purpose

The product turns scattered agent transcripts into a fast, searchable, shareable session workspace. Success means the user can find the right project, open the right session, understand context, inspect subagents, search transcript content, and share a stable deep link without fighting stale paths or missing auth.

## Brand Personality

Calm, archival, precise.

The interface should feel like a serious transcript console: quiet dark surfaces, clear source identity, legible long-form messages, and controls that stay out of the reading flow.

## Anti-references

- Generic analytics dashboards with decorative metrics and empty summary cards.
- Neon terminal styling that makes transcript reading tiring.
- Chat-app whimsy, oversized bubbles, playful avatars, or social-feed pacing.
- Ambiguous session links that appear to select a session but load the wrong project.

## Design Principles

1. Reading comes first. Message text, code, and tool output must stay calm and highly legible.
2. Source identity must be visible but secondary. Platform color identifies provenance, not decoration.
3. Deep links are product UI. Share, search, and canonical session selection should feel explicit and reliable.
4. Dense navigation is acceptable when it shortens the path from project to session.
5. Loading and truncation states must say what is available now and what is still being fetched.

## Accessibility & Inclusion

Keep keyboard navigation strong for search, sidebar, settings, and session selection. Maintain high contrast in dark mode, preserve focus-visible states, and do not rely on platform color alone without text labels.
